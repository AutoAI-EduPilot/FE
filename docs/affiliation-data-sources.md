# 소속 기관 데이터 연동 검토

## 결론

대한민국 대학과 대규모기업집단 소속 회사는 공식 Open API로 목록을
구성할 수 있다. 전체 중소기업을 공개 API 하나로 정확하게 분류하는
방법은 확인되지 않았으며, 공개 범위가 제한된 벤처기업·강소기업
데이터를 보조 자료로 사용할 수 있다.

API 인증키와 호출 제한이 있으므로 FE가 외부 API를 직접 호출하지
않는다. BE가 정기적으로 원천 데이터를 동기화하고 FE에는 검색 전용
API를 제공하는 구조를 권장한다.

## 권장 원천

| 구분 | 원천 | 활용 판단 |
| --- | --- | --- |
| 대학교 | 한국대학교육협의회 `대학 및 전문대학정보` | 학교명, 학교 유형, 지역을 제공하므로 1순위 |
| 대기업 | 공정거래위원회 기업집단포털 `대규모기업집단 소속회사 개요` | 법적 지정 기업집단과 소속회사 목록에 적합 |
| 공시기업 보완 | 금융감독원 OpenDART `고유번호` | 공시대상 회사명 검색 보완용이며 대기업 분류 기준으로 사용하면 안 됨 |
| 중소기업 일부 | 중소벤처기업부 `벤처기업확인서` | 벤처확인 기업만 포함하므로 전체 중소기업 목록이 아님 |
| 중소기업 일부 | 한국고용정보원 `워크넷 강소기업 검색` | 선정된 강소기업만 포함하므로 보조 목록으로만 사용 |

## 구현안

1. BE 배치가 대학·대규모기업집단 데이터를 주기적으로 내려받는다.
2. 기관명을 정규화해 `organization` 테이블에 저장한다.
3. 원천, 기관 유형, 원천 식별자, 기준일자를 함께 저장한다.
4. FE에는 `GET /api/organizations?q=&type=` 형태의 검색 API만 공개한다.
5. 검색 결과가 없어도 사용자가 직접 소속을 입력할 수 있게 유지한다.

중소기업은 공개 목록의 완전성을 보장하기 어렵다. 가입 단계에서는
직접 입력을 기본으로 두고, 벤처·강소기업 목록은 자동완성 편의를
높이는 범위에서만 사용하는 것이 안전하다.
